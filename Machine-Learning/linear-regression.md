# 线性回归

## 核心

线性回归是监督学习的一种模型：f(x) = wx + b
输入 x，算出预估值 y，与实际值比较，判断模型好坏。

样本数量：m

## 训练

- 使用梯度下降算法
- 学习率 α 决定收敛速度
- 当代价函数 J 接近 0 时，说明训练完成
- 每次迭代 = 用全部样本(有点好像是部分样本)算一次代价函数 + 更新一次 w 和 b

## 公式

- 代价函数：J = (1/2m) * Σ (f(xi) - yi)²
- 梯度下降：
  w := w - α * (1/m) * Σ (f(xi) - yi) * xi
  b := b - α * (1/m) * Σ (f(xi) - yi)

## 多变量线性回归

样本数量 m(行) 特征数 n(列)

本质和单变量一样，只是把 1 个 w 扩展成 n 个 w：
f(x) = w1x1 + w2x2 + ... + wnxn + b
梯度下降时，对每个 wi 和 b 分别求偏导并更新。

注：单变量时就如同一个一维数组，多变量则是二维的数组。

x(房屋面积，年龄，层数等) 每个x对应一个权重w**一般一个特征，就是一个 x,对应一个权重 w**

当只有一个w时 就像向下长的 数组（梯度下降计算时 从第一个到m个），

  f(x) = wx + b

多个w时 就扩展成二维的了 

(梯度下降计算时 也是第一个到m个，不过几个特征（w1,w2,w3...wn）)

 f(x) = w1x1 + w2x2 + ... + wnxn + b
